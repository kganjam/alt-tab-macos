## Current Code Review Fixes

- Removed unused native sibling-repair helpers and unused AX focus/raise helpers from `src/logic/Windows.swift`.
- Replaced broad full-stack expected z-order restore with scoped same-pid sibling demotion only.
- Skipped generic native AX raise recovery in fast z repair and enforcement; AX raise is now retained only for Parallels Coherence recovery where Parallels-specific evidence exists.
- Added a static release-risk evaluator to keep these footguns from silently reappearing.
- Added a live UserNotificationCenter popup-storm guard and log-scanner failures so UI evals abort instead of continuing through permission/dialog contamination.
- Reverted the release default native focus path to upstream-style `original` after logs showed the synthetic SkyLight-click path adding 0.6-1.7s on thumbnail/hotkey focus.
- Disabled artificial next-window repeat for key-coded shortcuts so holding only the modifier cannot continue cycling after Tab/` is released.
- Added native Cmd+`/Cmd+Shift+` registration protection and minimized-window deminiaturize-before-focus handling.
- Reverted unrelated-app cluster demotion; z repair is target-scoped again.
- Shortened default stale focus enforcement/suppression to 2.5s and made delayed modifier-only external hotkeys eligible to release stale enforcement.
- Added explicit release issues for raw same-app z clusters being imported into MRU order, non-layer-0 Teams-style auxiliary windows, and stale focus-event suppression fighting external activation.
- Added `REL-089` for Outlook↔OneNote same-boundary flashing/source clusters and slow Parallels gallery dismissal.
- Added `REL-100`/`REL-101` for the background-thumbnail IOSurface tally crash (`WSIOSurfaceDebugTallyAndAbort`) and the capture-path data races/null crash. Fixed by bounding the surface count via lifecycle (unregister-on-close + 30s zombie-GC reconcile + in-flight watchdog) while keeping thumbnails IOSurface-backed (GPU-resident, fast cold paint) — the unbounded growth, not the per-window surface, was the crash; `bgThumbnailDetachNonHotTier` (default off) detaches non-hot to malloc as a fallback; 3-tier cadence + minimized-skip; lock `cachedSCWindows`; snapshot per-window size/scale on the main thread (`CaptureRequest`) before the concurrent screenshots queue; nullable-guard `CGSHWCaptureWindowList`; stride-safe `isFullyTransparent`; token+watchdog `ActiveWindowCaptures`; computed `CGS_CONNECTION` (self-heals after a WindowServer restart). Mirrors upstream lwouis `f4a54c8f`.
- Fixed a defaults split-brain (`bgThumbnailWarmIntervalMs`/`JitterMs` were registered in `defaultValues` with old values that overrode the `RuntimeFlags` accessor defaults — relevant to `REL-056`). Dict and accessors must agree.
- Added the `THUMBCACHE` perf-level profiler line (`surfaces`, `windows`, etc.) so the held-surface count can be verified to track live windows (not grow unbounded) over long sessions.

## Residual Gaps

- The full dynamic matrix still has to prove the narrowed repairs do not regress Parallels flicker, native focus latency, same-app behavior, external hotkeys, and copy/paste.
- Dialog/popup, search/filter, sleep/wake, thumbnail freshness, display topology, and native Command-Tab restore remain partially manual or unevaluated.
