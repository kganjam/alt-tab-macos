# AltTab Focus Regression LLM Review Prompt

Use this prompt after any focus/z-order/performance change. The reviewer must read the supplied log excerpt and evaluator outputs as evidence, not rely on a single pass/fail line.

## Required Review Questions

1. Did any newer focus target receive a stale `app-activated` or `focused-window` event from an older target within the suppression window?
2. Did a Parallels/Coherence transition hide the panel before the target was actually top-visible and frontmost?
3. Did `parHideNow` hit or exceed its max-delay path, or report `ready=false`, `front=false`, or `target != top`?
4. Did `updatesBeforeShowing` or `show prep` exceed the configured latency budget, especially on repeated warm runs?
5. Did any `SAMEAPP`, stuck `CAPTURE`, unsafe native `level pin`, `nativeMultiWindowRepoke`, or `z0ActivationClick` signal appear?
6. Did final z-order, front process, AltTab selected window, and expected recency all agree?
7. Did the run include a matching end marker, and did it avoid restart contamination between markers?
8. Did any bounded eval window include mouse/key/user activity not generated by the evaluator?
9. Are any failures likely user-input contamination? If so, identify evidence and require a rerun rather than accepting the run.

## Output Format

- Verdict: PASS / FAIL / CONTAMINATED / INCONCLUSIVE
- Evidence: concise bullets with log lines or artifact names
- Missed Coverage: what this run did not test
- Required Follow-up: exact command(s) to rerun or fix
